# malariasimple_paper

This repository contains the R script and supporting code used in the analyses for the paper:

> **Shackleton, D.** et al. (Review). *malariasimple: An R package for fast simulations of malaria transmission*. PLOS Computational Biology.  
> DOI: 

---

## 📘 Overview

The R script `Shackleton26_simulations.R` reproduces the main results and figures presented in the manuscript. 
It uses the [`malariasimple`](https://github.com/mrc-ide/malariasimple) package for malaria transmission simulations.

The goal of this repository is to provide full computational reproducibility and transparency of the analyses described in the paper.

### Instructions for Use
1. Clone the repo (`git clone https://github.com/DebbieShack/malariasimple_paper.git`)
2. Set working directory to repo (`setwd("path/to/malariasimple_paper")`)
3. Run the main script `Shackleton26_simulations.R`
